Create a Nodejs application. The app download the following website:
https://hardverapro.hu/aprok/hardver/videokartya/nvidia/geforce_30xx/index.html

Then parse the content to have a list of products in a json. Each product in under the .media class.
I need the name of the product from .uad-col-title h1 and the time of publish in .uad-time, and the link to the page as well.
I also need the price of it from .uad-price, and if it's iced or not, .uad-price-iced class.

The application should return in a html the products where the name contains "12gb" in it and not iced, with an optional toggle to show all of them.

Only scrape the list once if the request happens within 30 minutes. Otherwise, use a cached response.
